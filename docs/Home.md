## What is FlowDesk?

FlowDesk is a production-ready, multi-tenant SaaS project management platform built with modern web technologies. It combines the best features of Jira, Trello, Notion, ClickUp, and Monday.com into a single, self-hostable solution.

---

## Key Features

| Feature | Description |
|---------|-------------|
| Kanban Boards | Drag-and-drop task management with customizable columns |
| Workspaces | Organize projects into team workspaces |
| Projects | Track project status, priority, and deadlines |
| Tasks | Subtasks, checklists, comments, attachments, labels |
| Dashboard | Real-time analytics and progress tracking |
| Notifications | Smart notifications for assignments and mentions |
| RBAC | Five permission levels from viewer to admin |
| i18n | English and Farsi/Persian with RTL support |
| Dark/Light Theme | System-aware theme switching |
| Mobile App | React Native (Expo) companion app |
